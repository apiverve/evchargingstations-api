# EV Charging Stations API

EV Charging Stations finds electric vehicle charging stations within a radius of a point, a ZIP or postal code, or a city, across the US and Canada, sorted by distance. Each station returns its address, coordinates, distance, status, access, network, Level 1, Level 2 and DC fast port counts and connector types. Filter by connector, network, charging level or fast charging only. Paid plans add charging power in kW, pricing, access hours, phone, facility type and open dates.

[![npm version](https://img.shields.io/npm/v/@apiverve/evchargingstations.svg)](https://www.npmjs.com/package/@apiverve/evchargingstations)

This is a JavaScript wrapper for the [EV Charging Stations API](https://apiverve.com/marketplace/evchargingstations?utm_source=npm&utm_medium=referral&utm_content=readme)

## Usage

---

### Perform Request

Using the API is simple. All you have to do is make a request. The API will return a response with the data you requested.

```javascript
var query = {
  lat: 37.7749,
  lon: -122.4194,
  zip: "10001",
  city: "Toronto",
  state: "ON",
  radius: 10,
  connector: "ccs",
  network: "Tesla",
  level: "2",
  fastOnly: false,
  access: "public",
  status: "open",
  limit: 20
};

api.execute(query, function (error, data) {
    if (error) {
        return console.error(error);
    } else {
        console.log(data);
    }
});
```

---

### Using Promises

You can also use promises to make requests. The API returns a promise that you can use to handle the response.

```javascript
var query = {
  lat: 37.7749,
  lon: -122.4194,
  zip: "10001",
  city: "Toronto",
  state: "ON",
  radius: 10,
  connector: "ccs",
  network: "Tesla",
  level: "2",
  fastOnly: false,
  access: "public",
  status: "open",
  limit: 20
};

api.execute(query)
    .then(data => {
        console.log(data);
    })
    .catch(error => {
        console.error(error);
    });
```

---

### Using Async/Await

You can also use async/await to make requests. The API returns a promise that you can use to handle the response.

```javascript
async function makeRequest() {
    var query = {
  lat: 37.7749,
  lon: -122.4194,
  zip: "10001",
  city: "Toronto",
  state: "ON",
  radius: 10,
  connector: "ccs",
  network: "Tesla",
  level: "2",
  fastOnly: false,
  access: "public",
  status: "open",
  limit: 20
};

    try {
        const data = await api.execute(query);
        console.log(data);
    } catch (error) {
        console.error(error);
    }
}
```
